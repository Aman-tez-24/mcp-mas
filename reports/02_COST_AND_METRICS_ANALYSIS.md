## 2. Cost Accounting Methodology (PDF Section 20)

### 2.1 The Mathematical Formulation
Model inference expense is calculated strictly on measured token counts returned by the runtime:

$$\text{Input Cost} = \left(\frac{\text{input\_tokens}}{1,000,000}\right) \times \text{input\_price\_per\_1m}$$

$$\text{Output Cost} = \left(\frac{\text{output\_tokens}}{1,000,000}\right) \times \text{output\_price\_per\_1m}$$

$$\text{Cached Cost} = \left(\frac{\text{cached\_tokens}}{1,000,000}\right) \times \text{cached\_price\_per\_1m}$$

$$\text{Call Cost} = \text{Input Cost} + \text{Output Cost} + \text{Cached Cost}$$

$$\text{Task Cost} = \sum_{\text{calls}} \text{Call Cost}$$

$$\text{Query Cost} = \sum_{\text{agents}} \text{Task Cost}$$

$$\text{Total Evaluation Cost} = \sum_{\text{test cases}} \text{Query Cost}$$

## 5. Audit Logging and Transparency
Every run produces an auditable record in `results/runs/<run_id>.json` capturing:
1. Exact subtasks generated by the Planner.
2. Every MCP tool invoked, including latency and returned passage records.
3. Every claim evaluated by the Verifier with its categorical status (`SUPPORTED`, `UNSUPPORTED`, `CONTRADICTED`).
4. Exact token counts and cost calculation outputs verified by the MCP `calculator` tool.
