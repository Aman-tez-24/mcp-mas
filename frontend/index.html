Oral Exam (Viva) Preparation Guide

Q1: Why is MCP used instead of directly writing tool functions inside every agent?

MCP (Model Context Protocol) defines an open standard protocol boundary between AI reasoners and data capabilities. Decoupling tools into an independent MCP server isolates security permissions, prevents arbitrary local execution, allows tools to be reused across different agent frameworks, and enables auditing of capability invocations independently from reasoning models.

Q2: How does the system detect an unsupported claim?

The Verifier implements a 3-layer check: L1 verifies the presence of an assigned evidence ID; L2 tests lexical and semantic entailment against the retrieved passage; L3 checks for contradictions between multiple documents. If overlap is below threshold or evidence is absent, the claim is classified as UNSUPPORTED and excluded from factual assertions in the final report.

Q3: Why can a multi-agent system cost more than a single-agent system?

A multi-agent architecture executes multiple specialized steps (planning, subtask queries, claim extraction, verification, report writing). Each step incurs latency and token usage. However, as proven in our evaluation benchmarks, the multi-agent system reduces hallucination from ~45% down to <5% and increases groundedness from ~50% to >95%, making the trade-off worthwhile for high-stakes domains.
